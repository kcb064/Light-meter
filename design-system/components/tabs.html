Meter screen header

Light Meter

Compact, not a TopAppBar: the meter screen uses a slim 16dp-padded row (title + trailing icon buttons) so everything fits on one screen. Sub-screens (Log, Settings, Calibration) use a standard Material top app bar with a back arrow. Tabs switch metering mode; the active tab is amber with a 3dp indicator. Incident is disabled when the device has no ambient light sensor.
