Anatomy: uppercase 12sp label → up arrow → 24sp medium value → down arrow, in an 88dp column. Steps walk a third-stop table by index — never free-form input. Swap, don't add: in aperture priority the row shows ISO · APERTURE · EC; in shutter priority the middle dial becomes SHUTTER. The solved variable is displayed in the readout, not dialed. Range ends: the arrow dims to outline gray when the stop table runs out (here EC at its limit). EC renders thirds as fraction glyphs: −1⅓, +⅔, 0 — with a true minus sign (−), not a hyphen.
